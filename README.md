# APEX PMS — Car Preventive Maintenance Dashboard

Dark-mode, gauge-driven PMS for vehicle **CCK 5751** (2024 · engine 6HK1-814133).

## Features

- Car-style interval gauge with Safe / Warning / Critical zones
- Automated status when cycle mileage approaches **4,500 km** (Warning) and hits **5,000 km** (Critical + notify)
- **Admin Board**: add/edit vehicles, input odometer KM, manage PMS materials, Save / Delete
- Multi-vehicle fleet selector (saved in browser `localStorage`)
- Live odometer simulator (`+250 km`) and oil-cycle reset
- Parts list and PM schedule log per vehicle

## Run

Open `index.html` in a browser (double-click or drag into Chrome/Edge).

No build step or Node.js required.
